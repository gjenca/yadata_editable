% The abstract

It is well-known that a function $f$ preserves an
equivalence or a quasiorder relation $\varrho$ if (and only if) each
unary polynomial function preserves $\varrho$ which can be obtained from
$f$ by substituting constants at all but one arguments. Thus the
polymorphism clone $\mathrm{Pol}\,\varrho$ is completely determined by the
endomorphism monoid $\mathrm{End}\,\varrho$. 
\emph{Generalized quasiorders} are higher-ary relations with the same property.
We describe the generalized quasiorders of (almost all) maximal
clones on a finite set.
